# Online-Tools-Hub

A fully functional, SEO-optimized, multi-language web platform offering a collection of mini internet utilities for downloading videos from popular social media platforms.

## Features
- Download videos from YouTube, Facebook, TikTok, Instagram, Twitter, Reddit, and Pinterest
- Multi-language support (English and Arabic)
- SEO optimization
- Responsive design using Tailwind CSS
- Server-side handling to avoid CORS issues

## Tech Stack
- Frontend: React.js with Tailwind CSS
- Backend: Python FastAPI
- Downloader engine: yt-dlp
